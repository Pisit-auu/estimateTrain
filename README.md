# รถมาหรือยัง · รถไฟฟ้ากรุงเทพฯ

เว็บหน้าเดียว (static HTML) สำหรับดูว่ารถไฟฟ้าขบวนถัดไปจะมาถึงสถานีเมื่อไร และวางแผนเดินทางข้ามสาย

- สาย: MRT สายสีน้ำเงิน, MRT สายสีม่วง, BTS สุขุมวิท / สีลม / สีทอง, สายสีเหลือง, สายสีชมพู (รวมสาขาเมืองทองธานี), สายสีแดงเข้ม / แดงอ่อน, Airport Rail Link
- แผนที่แบบรางคู่ แสดงขบวนถัดไปที่กำลังวิ่งเข้าสถานี
- เลือกปลายทาง แล้วคำนวณเส้นทางที่ถึงเร็วที่สุด พร้อมจุดเปลี่ยนสายและเวลาโดยประมาณ
- จำลองเวลา (เลือกชั่วโมง/นาที และเร่งความเร็ว)

## ที่มาของข้อมูล
| สาย | แหล่งข้อมูล |
|---|---|
| MRT สายสีน้ำเงิน | โปสเตอร์ตารางเวลาเดินรถ (เที่ยวแรก/สุดท้ายรายสถานี และความถี่) |
| MRT สายสีม่วง | ตารางเวลาเดินรถฉบับ 11 ส.ค. 2560 |
| BTS, สายสีเหลือง, สายสีชมพู | เว็บไซต์ BTS (เที่ยวแรก/สุดท้ายรายสถานี และความถี่) ดึงเมื่อ 5 พ.ย. 2569 |
| สายสีแดง | srtet.co.th (เวลาออกรถทุกเที่ยว ฉบับวันธรรมดา) ดึงเมื่อ 5 พ.ย. 2569 |
| Airport Rail Link | ไม่มีตารางทางการ ใช้ค่าประมาณ (05:30–00:00, ~27 นาทีตลอดสาย) |

ข้อมูลดิบที่ดึงมาอยู่ใน `data/` เวลาทั้งหมดเป็นการประมาณ ไม่ใช่ตำแหน่งรถจริง
